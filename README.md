# Sprint 3 — Grocery Demand Forecasting Prototype

This starter project is intentionally simple.

## Files
- `streamlit_app.py` — main Streamlit application
- `data/favorita_weekly_sales.csv` — cleaned full-history dataset
- `requirements.txt` — Python packages used by the app

## Current starter functionality
- Loads the cleaned Favorita dataset
- Uses Store 44
- Lets the user select Beverages, Dairy, or Bread/Bakery
- Shows historical weekly sales
- Shows cleaned promotion and holiday/event information

## What we will add next
1. Four-week baseline demand forecast
2. Forecast validation / simple accuracy measure
3. Promotion scenario adjustment
4. Current inventory and safety-stock inputs
5. Recommended replenishment quantity
6. Simple stock-risk indicator
7. Final testing and deployment

## Recommended platform
Use GitHub + Streamlit Community Cloud + GitHub Codespaces so the team can work in the browser without installing Python locally.
